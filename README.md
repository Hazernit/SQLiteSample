# SQLiteSample

Учебное приложение на **C# Windows Forms** для работы с базой данных **SQLite**.  
Проект разработан в рамках лабораторной работы по теме работы с базами данных в **.NET**.

## Описание проекта

Программа предназначена для работы с базой данных студентов в режиме **Runtime mode**, то есть с возможностью выбора и подключения базы данных во время работы приложения.

В приложении реализованы основные операции работы с БД:

- подключение к базе данных SQLite;
- просмотр записей;
- добавление новых записей;
- редактирование существующих записей;
- удаление записей;
- фильтрация списка студентов по группе;
- фильтрация списка студентов по факультету;
- подсчет количества студентов.

## Цель работы

Изучить основы работы с базой данных SQLite в среде **C# / Windows Forms**, а также реализовать графическое приложение для управления данными студентов.

## Используемые технологии

- **C#**
- **Windows Forms**
- **SQLite**
- **ADO.NET**
- **Visual Studio**

## Функциональные возможности

Приложение позволяет:

1. Выбрать файл базы данных во время выполнения программы.
2. Подключиться к существующей базе данных SQLite.
3. Отображать данные из таблиц базы.
4. Добавлять новые записи о студентах.
5. Редактировать существующие записи.
6. Удалять записи.
7. Выполнять выборку студентов по выбранной группе.
8. Выполнять выборку студентов по выбранному факультету.
9. Подсчитывать количество студентов.

## Структура базы данных

В базе данных используются таблицы, связанные со студентами, группами и факультетами.

Пример логики данных:
- **Student** — информация о студенте;
- **Group** — информация о группе;
- **Faculty** — информация о факультете.
